# Campus Radar 阶段一：公开来源普查与字段复核

核验日期：2026-10-28。来源主记录为 `data/sources.json`；本文件说明当次证据、抽查范围与缺口，不建立第二份可编辑来源注册表。

## 结论及计数口径

本轮记录 **27 条不同渠道/栏目调查对象**，覆盖任务书要求的 8 个产品类别。它们包括 16 个网站栏目、2 个网站门户、1 个官方社团目录、1 个志愿者介绍页、1 个待定位栏目的网站种子、6 个公众号线索。组织数量、站点数量和栏目数量没有混算。

当前主清单为 **3 条“采集已验证”、14 条仅“入口已确认”、9 条“候选”、1 条“受阻”**。最初普查的 17 条已确认入口中，三站现已完成真实采集、入库、查询、导出与重跑；`enabled=true` 本身仍不表示成功。技术结果以 `docs/ACCEPTANCE.md` 为准，原始网络失败保留在每源 `previous_check` 中。

`latest_sample` 表示本次列表首项或取得的近期样本，不保证为整个账号/栏目最新文章。未取得URL、标题或发布时间时为 `null`。网页标注的日期可保留为原始证据，但存在异常时在 `last_error`/`coverage` 说明，不自行修正。

## 发现路径与证据等级

从[学校组织目录](https://www.sjtu.edu.cn/jgsz/)确认新闻中心、研究生院、国际处、学生创新中心、教学发展中心及基础教育办公室等单位的官方站点；再读取相应官网导航，定位栏目和正常详情链接。搜索用于补漏与取得公开页面证据，不替代可复跑采集器。

- `official_navigation`：官方站点导航或栏目页面的直接证据。
- `official_statement`：官方页面明确提到公众号名称、账号或职责；仍不等于公众号文章可采集。
- `community_directory`：仅作线索。SJTU Wiki 的“官方”描述不独立证明运营主体、活跃度或持续可采集性。
- `task_brief_seed`：任务书种子，仍需确认当前页面有效性。

未读取 jAccount 登录后内容，未尝试报名、发送消息或修改任何校园业务数据。第二课堂验证路径由独立的 `docs/auth_probe.md` 记录。

## ME砺远学术专项核对

[机动学院官方流程说明](https://me.sjtu.edu.cn/index-zytz/70516.html)的页面日期为2023-04-12，正文分别描述学院宣传办公室在官网发布报告信息，以及砺远学术组委会在“ME砺远学术”公众号推送并组织报名。学术报告栏目页脚也直接列出该公众号名称。该证据支持其官方业务关联；未核实永久账号ID或微信认证主体。

官方流程链接一个[公众号推送示例](https://mp.weixin.qq.com/s/Ef4vdmWFOR_tsgFRWVBtIA)，本轮网页工具返回不可重试错误，未取得文章正文。因此没有构造公众号摘要，也未把它导入采集库。

| 核对问题 | 本轮结论 |
| --- | --- |
| 是否存在官方身份线索 | 有：学院官网页脚及正式发布流程。 |
| 是否取得可采集公众号正文 | 否；仅取得官方给出的文章URL。 |
| 官网是否会向公众号提供信息 | 流程说明允许转发官网报告链接给组委会；这是工作流程证据。 |
| 官网与公众号是否逐条、全文、及时同步 | 未知；没有成对文章对照。 |
| 公众号是否有官网没有的会议信息 | 未知；用户所述痛点尚不能被本轮数据证实或排除。 |
| 持续采集及当前活跃度 | 未验证。 |

下一步应在正常可访问条件下取得少量成对文章，分别核对标题、时间、地点、报名要求与发布日期；不能从流程文字推断自动同步，也不能为了取得正文绕过微信访问限制。

## 10篇正文的逐字段阅读复核

机器可读审核文件为 [`samples_review.json`](samples_review.json)：校级讲座3篇、机动报告4篇、教学发展中心3篇，共10个不同文档URL、3个站点。采样是有目的抽查，不是随机样本。复核由Codex逐项阅读公开文本完成，未获得用户本人审核；`user_human_reviewed=false` 明确记录这一点。

每条分别核对标题、发布时间、活动时间、地点、资格、报名截止和出处；保留短事实证据、原句时间与未知值。关键发现如下：

1. 校级讲座226851的URL目录日期是10月23日，页内发布日期是10月22日；不能从URL覆盖页内发布日期。
2. 机动4篇报告的“发布时间”均为未来日期并与举办日相同。保留原值并标异常，不据此计算发现延迟。
3. 4篇样本有明确结束时间且已结束；另1篇讲座只给过去开始时刻、未给结束时刻。不能推荐为现在可参加。
4. 教学发展中心“计算机网络课程”讲坛正文只写月日；完整HTML活动头明确提供2026/09/29 11:50–13:20，现用该直接证据补齐年份，不从人物简介推断。
5. 教学学术年会通知含工作坊和论文两类截止，分别保留上下文，24:00未被误改成同日00:00。完整正文另明确大会日期为2027年4月16–18日、地点为闵行校区（线下），现有直接证据；原末署日期不充当CMS发布时间。
6. “请有兴趣的同学/老师”只作为面向对象，不扩展成完整资格条件；机动报告未明确资格时保持未知。
7. 海报和附件没有完成OCR或内容解析，不能称字段已完全覆盖。

原审核基准没有作为数据导入正式库；随后由正式 Fetcher 从这10个URL取得完整HTML、解析并入库。`collector_comparison` 现记录标题、时间、地点、完整资格和出处共50项源文对照，另保存哈希、原文补证及未知项。此项由Codex审阅，不是用户本人复核，也不用于宣称全站准确率或全校召回率。

## 当前保留的未验证项

- 全部来源的持续可用性、发现时延、历史分页完整性。
- 公众号正文采集，官网/公众号重复与独有内容。
- 志愿服务和文体社团的当前公开招募供给。
- 登录来源、用户实际可见范围及第二课堂两个入口的同源关系。
- 每日更新或长期使用价值。用户已接受本轮Codex逐字段对照作为第一阶段门槛，审阅者事实仍保持为Codex，并非用户本人复核。

来源的可复跑网络检查失败应保留历史和错误，不视为“没有活动”。只有对应完整流程有真实执行证据后，才把某条主清单状态改为“采集已验证”。

**CTLD列表范围有误。** 当前实现[扫描全页锚点](../campus_radar/collector.py#L176)，将顶部导航中的“2026年学术年会”作为第一条记录。其链接虽符合详情路径，但位于`dropmenu-container`，不属于`event-list`活动列表；见[原始HTML第259行](../outputs/network-diagnosis/ctld.sjtu.edu.cn-bound-en0.html#L259)。该记录会占用文档采集预算。离线将候选限制为`event-list`中的活动卡链接后，得到12条，而不是13条。

**三站均遗漏下一页。** 这三份页面有明确的分页证据，当前`next_url=None`不能解释为已到末页：

- News分页由内嵌JavaScript配置生成，当前页1、总页数100，第二页地址为`/xsjz/index_2.html`；原始HTML没有可直接提取的下一页锚点。见[分页配置第244行](../outputs/network-diagnosis/news-bound-en0.html#L244)。
- ME已有“下页”锚点`/tsfx-xsbg/p2.html`，页面显示17页；但当前[`LIST_PATHS`第31行](../campus_radar/collector.py#L31)只接受`tsfx-xsbg_数字.html`形式，因此拒绝真实分页路径。见[原始HTML第757行](../outputs/network-diagnosis/me.sjtu.edu.cn-bound-en0.html#L757)。
- CTLD分页同样由内嵌JavaScript生成，当前页1、总记录数976、每页12条，第二页使用`page=2`，并保留搜索词、`group_id`和`atagId`。976是页面配置值，不是本次采集数量。见[分页配置第1184行](../outputs/network-diagnosis/ctld.sjtu.edu.cn-bound-en0.html#L1184)。

News和CTLD的脚本会被`page_tree`移除，当前仅查找下一页锚点的逻辑无法读取这些配置。最小适配方向是接受ME的真实分页路径，并从News/CTLD原始HTML中的明确分页配置生成受限的下一页URL，同时保留现有来源主机和页数预算检查。这里只记录适配缺口，没有遍历后续页面或验证其内容。

**列表标题包含整张卡片文本。** 当前[第182行](../campus_radar/collector.py#L182)对整个锚点取文本，把活动时刻、地点等拼入`title`。例如News第一条的输出以“2026-10-27 18:30-20:00”开头，真正标题为“科研与求学——本科生科研建议”。离线分别使用News的`p.title`、ME的`p.line-1`、CTLD的`div.title`提取卡片标题，得到10/12/12个独立标题，缺失数均为0。详情解析会另取正文标题，因此本项不能直接证明最终入库标题同样错误。

**CTLD审核样本首页仅命中1/3，不是另外两条被解析漏掉。** “中国高校第九届教学学术年会征稿通知”（`13wft64voa11do0tp1f0utg19mko91ul`）在原始HTML锚点和解析结果中都存在；英语学习营（`1fn95z2o1kab10f6k216wv0a1jw6hf1k`）与计算机网络讲坛（`i2bi77eq56n9q0xko4uhu08h33ju57d7`）在这份首页的全部原始锚点中均不存在。News的3条和ME的4条审核URL则全部在原始锚点和解析结果中命中。此检查只确认同URL的列表可见性，没有改变[`samples_review.json`](samples_review.json)中的详情字段基准，也不能据此计算详情字段正确率。


## 修复后的结果

三站列表已限制到实际卡片区域，标题独立提取；News/CTLD的脚本分页及ME真实下页路径均已适配。各站首两页实读，新闻为10/10、ME和CTLD均为12/12，页间详情链接不同；末页停止与过滤条件保留有离线测试。详情选择器、新闻活动头、CTLD活动头补年、日期区间、受众和不同投稿截止已修正。实际覆盖范围、原生侧栏与代理切换记录统一见 [ACCEPTANCE.md](ACCEPTANCE.md)，不把这里的历史缺陷表作为当前结论。
