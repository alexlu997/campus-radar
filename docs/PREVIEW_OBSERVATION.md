# 预览版七个实际使用日记录

状态：准备中，工程验收与实际使用价值分别记录。不能用同一天重复采集、修改系统日期或自动测试抵扣实际使用日。

## 记录口径

- 运行证据读取日常数据库的 `updates`、`runs`、`settings` 和文档时间，不读取或复制 WeRSS 凭据。独立验收数据库不参与统计。
- 按 Asia/Shanghai 自然日汇总计划执行、各官网成功／失败、补扫剩余与错误。没有运行记录时记为缺口，不能记成正常。
- 只有发布时间可解析、无未来日期异常、时间精度足够且确属观察期首次发现的文档，才计算发布到发现的延迟。只有日期的发布时间给区间或单列；未知、异常和历史补扫不纳入及时率。
- 公众号另列授权／限流状态和有原文证据的新发布；旧快照、缓存重存和官网成功不能替代公众号新文章成功。
- 用户的明确反馈或实际收藏等操作可以作为使用事件；自动化检查产生的状态不得计入。没有明确价值反馈时，“发现有用信息”“重复”“实际漏项”等维持未知，不推断产品价值通过。
- 七个日期的运行记录与七个实际使用日是不同的计数。若用户某日没有使用，顺延到取得第七个有证据的实际使用日，再进行价值总结。

2026-10-28 部署前：日常库 40 篇文档、34 个活动／截止事项，收藏 0、明确反馈 0；公众号保持用户原有启用状态。当天过去的三次四源定时批次为部分完成，官网成功、公众号受限。新版本部署时间与核对结果将在部署后补记。
