## 请求路径与实际开关验证

只对 `data/sources.json` 中三条已启用公开来源使用 `network_mode=direct`。每次请求读取 macOS 当前物理 IPv4 接口，独立 HTTPS DNS 按 TTL 缓存真实公网地址，再以该接口请求原 HTTPS 域名，保留 SNI、证书验证、白名单、robots.txt、请求限额。接口或连接异常时清理解析缓存、重新识别，最多重试一次；TLS 校验失败不重试降级。

独立解析使用 `dns.alidns.com` 的公开接口；固定的是解析服务的引导地址，校园站点 IP 未硬编码。没有修改系统代理、TUN、DNS、路由或用户代理软件配置。本轮所有开关均由用户手动完成。当前实现验证范围为本机 macOS、IPv4、`en*` 物理接口；其他系统与网络条件未验。
