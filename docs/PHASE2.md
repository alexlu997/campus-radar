## 在线检索与公众号结论

官网固定复测查询为“机器学习”“AI”“征稿”。公共接口在返回候选结果前就受限，无法计算它们的召回率或内容质量；当前只能比较可访问性，不把官网搜索与全网搜索宣称为等价能力。

| 方法 | 本轮观察 | 采用情况 |
| --- | --- | --- |
| 公共 SearXNG：`www.isci.si`、`priv.au` | JSON 请求均返回 HTTP 429；未获得候选链接 | 不接入日常链路 |
| DuckDuckGo HTML | 返回验证页面；没有把页面中的普通链接作为搜索结果 | 不接入，不绕过验证 |
| CTLD 官网关键词检索 | AI 12 个候选且还有下一页；征稿 6 条；机器学习页面明确 0 条 | 接入“在线补漏”，当前每次查询读取一页，最多保存 30 条；结果数不代表全站总量 |
| Tavily／Exa／Firecrawl 等 | 本轮没有可用 API 配置，按用户限定未申请账户或付费调用 | 未实测、不作为已选能力 |
| WeRSS | [官方使用说明](https://github.com/rachelos/we-mp-rss/blob/main/README.zh-CN.md)要求使用微信扫码授权后管理订阅 | 本轮不安装或登录，未证明 ME 砺远学术持续获取可用 |

早期 `ctld-search.json` 将“机器学习”的空列表当成解析失败。修复后根据网站明确的零计数判断，真实复测保存在 `search-probes/chosen-provider-final.json`；不是把无匹配链接一律解释为零结果。

微信样本：[官网给出的文章链接](https://mp.weixin.qq.com/s/Ef4vdmWFOR_tsgFRWVBtIA)。采集器遵守该站 robots 规则，结果为 `failed`、`document_id=null`。缺失正文意味着：账号正文身份、官网同步／不同步情况、公众号独有机会、持续稳定性都仍未验证。手工入口不会把链接保存成功写成正文获取成功。
