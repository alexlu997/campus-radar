# 校园雷达

校园雷达是运行在 DSH 侧栏中的本地活动信息工具：采集公开官网文章，整理活动与截止事项，提供搜索、收藏、明确反馈和每日规则简报。

当前版本为 **macOS 预览版 `0.2.0-preview.2`**。安装包包含 JavaScript 插件、Python 核心和公开来源配置；个人数据库、登录状态和缓存独立保存在用户目录。源码及安装包发布在 [GitHub](https://github.com/alexlu997/campus-radar)。七个实际使用日的持续运行与价值验证单独记录，尚未完成。

## 安装

要求 macOS、Python 3.13 和 DSH `0.2.1-rc.3`。从固定 GitHub 标签安装并初始化独立 Python 环境：

```sh
dsh_cli="/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh"
"$dsh_cli" plugin --profile desktop add github:alexlu997/campus-radar#v0.2.0-preview.2 --ignore-scripts
"$dsh_cli" plugin --profile desktop exec campus-radar setup
```

重新启动该 DSH 实例，在侧栏打开“校园雷达”。完整的依赖、后台任务、升级、卸载和独立数据目录说明见 [安装说明](docs/INSTALL.md)。

## 功能

- **来源更新**：默认启用三个官网栏目，有单次请求预算、跨轮补扫、失败恢复和仍有效活动的原文复查。来源页显示请求结果与待补扫范围。
- **活动库**：一篇文档可包含多项活动或截止事项，同一活动可以保留多个出处；时间、地点和资格未知时不补造信息。
- **查询与详情**：标题／正文搜索，以及来源、类别、校区、日期和状态筛选；可查看原文、字段证据和变更。
- **收藏与反馈**：收藏、关注主题与来源、感兴趣／不感兴趣／已经知道均保存在本机。偏好影响简报，不缩小来源采集范围。
- **每日简报**：优先重要变更和临近截止，再选择尚未入选的内容；未入选且仍有效的候选可以顺延。提供入选理由，候选不足时不凑数。
- **在线补漏**：支持教学发展中心官网关键词搜索，以及人工保存和获取已支持网站的文章链接。
- **后台更新**：可选的 macOS launchd 每日任务，退出 DSH 后仍可执行；与手动更新复用同一套业务逻辑和数据库锁。

## 当前覆盖与限制

默认来源为学校新闻学术网的学术讲座、机动学院学术报告和教学发展中心活动。登记其他入口不表示已经支持采集。每轮默认最多读取每源 12 篇正文、2 个列表页；请求成功不表示整个栏目已覆盖，剩余工作会明确记录。

ME 砺远学术为需要本机授权的可选来源，默认关闭。最新一篇正文路径已验证，但不能回补历史，两次检查之间连发多篇可能遗漏，且近期出现限流。官网能力不依赖公众号授权。

海报 OCR、附件解析、系统推送、复杂推荐和全网搜索尚未实现。实际整机睡眠／唤醒尚未验证；本机隔离安装验收不能代替第二台机器验证。公开采集与规则简报无需模型或搜索 API Key。

## 源码开发与检查

```sh
python3 -m unittest discover -s tests -v
node --test plugin/test.mjs
```

Python 运行依赖固定在 `requirements.txt`。浏览器验收或单独登录准备使用的 Playwright 不属于官网日常运行依赖。

开发时也可直接使用 `python3 -m campus_radar --help`。指定独立数据库运行验证，不要把临时收藏、偏好和验收样本写入日常数据库。当前阶段与历史证据保存在源码仓库的 `docs/` 和被 Git 忽略的 `outputs/` 中。
